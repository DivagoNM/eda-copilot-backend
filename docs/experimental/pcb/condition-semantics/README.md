# Семантика условий размещения, 2026-10-07

Предыдущая правка обычных сетей сохранена коммитом `a935378`.
Эта итерация исправляет смысл и транспорт условий, без калибровки весов.
Rust остаётся источником оценок; score contract v10 требует пересборки addon.

## Что изменено

| Условие | Раньше в Block/Board | Теперь |
| --- | --- | --- |
| away_from | Обычное притяжение `distance × weight` | Штраф только за недостаточный зазор; минимум 8 мм, high/critical — 12 мм |
| clearance | Терялся авторский min; притяжение | Авторский min доходит до обоих native solver; critical участвует в hard rank |
| same_side | Притяжение; PostPlace игнорировал группы | Только несовпадение слоёв; все участники группы учитываются |
| prefer_layer | Терялся layer; иногда штраф внешнего порта | Только несовпадение выбранного слоя, включая группы |
| edge | Терялся выбранный край; иногда штраф внешнего порта | Расстояние от bbox источника до указанного края всей платы |
| clearance(block, all) | PostPlace сравнивал блок с его собственными деталями | Из all исключаются все участники source; чужие детали по-прежнему проверяются |
| Board FastRoute | Пустой ignoredNets | Передаётся исходный список, регистр не влияет |

Условия не проходят через обычную формулу расстояния или exposure/facing.
Контуры групп собираются из настоящих участников, в том числе находящихся в
разных ещё подвижных примитивах. Они не подменяются bbox родителя. В partial beam
условие оценивается, когда присутствуют все его локальные участники. Внешняя
неизвестная цель откладывается, а не превращается в притяжение.

Для заданного зазора используется прежняя геометрия PostPlace — полный bbox
footprint, для pin — точка пина. Это отдельная геометрия от occupiedAreas,
применяемых физическим collision scorer. Chebyshev gap между bbox сохраняется;
формула зазора не заменяется евклидовым расстоянием. Отрицательный gap означает
перекрытие. clearance не приобретает нового исключения для разных слоёв.

## Веса сохранены из PostPlace

`W = 25 / 70 / 140 / 240` для low / normal / high / critical.

- clearance/away: `20 × W × max(min − gap, 0)²`.
- same_side: `20 × W` за условие, если объединение слоёв участников неоднородно.
- prefer_layer: `10 × W` за условие, если хотя бы один участник на другом слое.
- edge: `W × abs(расстояние до выбранного края)`.

Групповое условие слоя получает один штраф, а не штраф за каждую пару деталей.
Пустая/внешняя группа не создаёт фиктивного нарушения. away/same_side/prefer_layer
остаются мягкими и при critical, как в PostPlace; critical clearance/edge — hard.
У Board сохраняется дополнительный существующий множитель hardSeverity 1e6:
совпадение мягкого члена не означает равенства полного ранга разных этапов.

Пример: две детали 1×1 мм, normal away_from. При расстоянии центров 2 мм gap=1,
поэтому штраф равен 68600 на всех трёх этапах. При 10 и 20 мм он равен нулю.
Раньше Block/Board давали соответственно 20, 100 и 200 — именно притяжение.

## Переиспользование и GPU

- `native/conditions.rs`: один план принадлежности, упаковка GPU-данных,
  общий CPU/CubeCL код gap, clearance, layer, edge и hard violation.
- Геометрические адаптеры Block/Board используют существующие преобразования
  точек примитива. Производные `@hint:`-углы не являются сетями и не меняют
  порог количества электрических endpoints в power-yield/frontier.
- Полный расчёт условий и hard rank остаётся на GPU вместе с кандидатом;
  CPU не пересчитывает эти штрафы для каждого GPU-кандидата.
- PostPlace использует те же арифметические функции. Его GPU layer terms
  разрешают группы, а scalar scorer и GPU encoder исключают одних и тех же
  участников source из all.
- TS Block/Board используют один `native/encode-relation.ts`.
  PostPlace score/refine используют общую функцию targetDesignators.
- Сохранён строгий контроль inventory pairSeed; производная геометрия готовится
  до проверки. Проверяются как обычный solve, так и продолжение парного поиска.

## Границы исправления

Локальный Block без world не знает положение края всей платы и откладывает edge.
Он не использует края локального bbox как подмену края платы. Board и world-aware
Block считают его по полной плате.

У edge восстановлен выбор left/right/top/bottom. Legacy orientation
outward/inward/any сохраняется в транспорте и capture, но отдельного нового
штрафа направления корпуса в этой итерации нет: его раньше не было и в PostPlace.
Механическое направление задаётся существующими faceTo/edgeMount/edgePlace и
allowedRotations. Нельзя считать legacy orientation самостоятельно реализованным
мягким критерием; для группы ещё нужно определить, чьё физическое направление
имеется в виду. Это отдельный открытый пункт, а не молчаливое угадывание оси группы.

ignoredNets исключает обычную геометрическую связь, но не удаляет pad obstacles
и не отменяет явно авторизованные critical_pair/signal_path. Это сохраняет
действующее правило приоритета явно заданных цепочек.

Остальные различия полной целевой функции (компактность, access, structural
islands), старые CPU/GPU пограничные расхождения и качество отдельных маршрутов
не объявляются устранёнными этой правкой.
