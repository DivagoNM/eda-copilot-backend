# Обычная связность Board — 2026-10-07

## Объём

Пользователь разрешил учитывать расстояния всех обычных сетей, ограничить
общую силу связи двух блоков и проверить снятие насыщения расстояния,
включая более пологий рост после 40 мм. Остальные семантические проблемы
условий (`away_from`, `clearance`, слои, края, исключения сетей) не изменяются.
Предыдущая калибровка FastRoute зафиксирована коммитом `3fa3a77`.
Пользовательский STM32 DSL сохраняется и не входит в этот коммит.

## Оценка

Для каждой пары примитивов A/B и каждой соединяющей их сети n:

- `w_n = net_weight / (owner_count - 1)` — существующая нормализация fanout;
- `d_n` — ближайшее расстояние между площадками **этой сети** на A/B;
- `W = sum(w_n)`;
- `P_AB = 0.5 * min(1, 4/W) * sum(w_n * f(d_n))`.

Board сохраняет внешний множитель 5 для normal и 3 для high compactness.
Вес питания 0.1, отсев ground/ignored и fanout более восьми примитивов
сохраняются. Сильные явно заданные связи и FastRoute не перенастраиваются.

| Профиль | Расстояние | Объединение сетей |
|---|---|---|
| Baseline | `min(d, 30)` | Минимум расстояний всех сетей × ограниченная сумма весов |
| Linear | `d` | Все сети, ограниченная сила пары |
| Tail | `d` до 40; `40 + 0.25*(d-40)` после 40 | Все сети, ограниченная сила пары |

Пологий хвост применяется к каждой сети до усреднения. Насыщения нет:
40/60/80 мм превращаются в 40/45/50 эффективных мм в профиле Tail.
Предел силы пары не ограничивает суммарное притяжение от нескольких
разных разъёмов. После достижения предела каждая отдельная сеть
продолжает влиять, но её вклад уменьшается с количеством связей.
Ближайшая площадка внутри одной многоточечной сети остаётся приближением;
это не полноценная длина разводки или замена маршрутной оценки.

## Переиспользование

`ordinary_net.rs` содержит общий план пар/сетей, фильтрацию маркеров,
нормализацию, порядок редукции и CPU/CubeCL функции стоимости.
Board GPU сохраняет свой кэш индексов площадок и планов, используя общий
построитель. Block GPU использует тот же план, хотя обычные маркеры
создаются прежде всего адаптером Board. GPU-ядра сохраняют отдельное
извлечение геометрии из своих resident buffers, вызывая общую арифметику.
CPU recovery и quality evaluation используют тот же native objective.
Контракт оценки повышен до v9, требуется пересборка addon.

## Результаты полных прогонов

Входы `placement/input.json` и исходные fixture files совпадают по SHA-256
между профилями каждой платы. Проверено сохранение всего инвентаря и всех
fixedPlacement. У всех девяти результатов `placementOk=true`; три результата
ESP32 имеют exit 1 из-за прежней проверки `graphReport.ok`, остальные exit 0.
Два baseline повторно использованы, семь полных captures сняты в этой работе.
Прогоны/сборки выполнялись последовательно, без конкурирующих тяжёлых заданий.

Длины — диагностический MST с исходным фильтром ignored nets. Explicit length
и crossings измерены по уникальным явно заданным прямым pad-to-pad связям;
crossings переиспользуют Rust FastRoute `crosses`. Это не результат трассировки
и не дополнительный scorer. Абсолютные scores разных профилей не сравниваются.

  U3/U4/U5 и D4 сохранились, D4 остаётся на 0°. Два пересечения RS485 остаются.

  D13.1–J4.4 остаётся 18.085 мм при максимуме 6 мм во всех трёх профилях.

Массового перетягивания блоков к разъёмам здесь не обнаружено. Новая обычная
связность остаётся слабым членом полной оценки; исправление потери расстояний
не гарантирует уменьшение диагностического MST или устранение уже известных
неудачных компоновок. Генерация кандидатов, ширина Beam и локальный поиск
не менялись.

В каждом профиле Board фактически использовал CubeCL GPU. Полное время
включает подготовку GPU, планирование и CPU recovery отдельных блоков.

встречаются также admission/initialization pending. Подробности сохранены в
`results.json`. Один проход на профиль не доказывает ускорение Tail; на двух
малых платах время Board относительно Baseline немного выросло.

## Решение

Оставлен **Tail: порог 40 мм, наклон 0.25, без потолка** согласно согласованному
эксперименту. Его преимущество — заданное ограничение силы дальнего
притяжения при сохранении чувствительности к расстоянию. Он не объявляется
эмпирически лучшим по качеству: Linear дал те же итоговые позиции.
Остальные выявленные семантические рассогласования остаются отдельной работой.
